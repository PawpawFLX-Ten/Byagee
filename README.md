# Civic Man

网页版第三人称无尽生存小品：在包间里制止 CPU 角色吧唧嘴，噪音过高会掉血。

## 运行

```bash
npm install
npm run dev
```

## 操作

| 按键 | 作用 |
|------|------|
| WASD | 移动 |
| 拖拽 | 旋转镜头 |
| Tab | 切换目标 |
| 1 | 拍 |
| 2 | 胶条 |
| 3 | 喇叭 |
| 4 | 塞嘴 |
| R | 死亡后重开 |
