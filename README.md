# Civic Man

网页版第三人称无尽生存小品：在包间里制止 CPU 角色吧唧嘴，噪音过高会掉血。

## Round 2

- **门系统**：NPC 从北门进出，人口上限 10（含 Boss）。插件随时间解锁（定时 → 威胁驱动 → 座位驱动）。
- **三桌布局**：圆桌、方桌、椭圆桌三角分布，共 10 座位。
- **Boss**：每 3 分钟生成一个（最多 1 个），体型 1.4×，含嘴 HP / 抗性 / 暴怒三模块（按时间叠加）。击败后降为普通食客。
- **拍喊**：slap 命中时播放「操你妈」语音。

## Round 5

- **道具系统**：每 45 秒在地上刷新一个道具，走过自动拾取。
- **回血药**：红色胶囊 + 绿十字，恢复 35 HP（满血上限）。
- **静音符**：金色铃铛 + 蓝色「静」字，全场普通 NPC 静音 5 秒（Boss 免疫）。
- **HP 权重**：血量越低越容易刷出回血药（满血 50/50，残血 95% 回血）。
- **视觉**：道具悬浮 + 旋转 + 发光光环；拾取时缩小消失；HUD 边缘金色 ✦ 指引方向。
- **持久化**：道具不捡不会消失，多个可同时存在。

## Round 6

- **开屏精简**：删除公文抬头和等级制度说明，赞助按钮移入标题行，字号放大，全设备无滚动条。
- **赞助改版**：三段两端对齐文案，爱发电链接更新，标题改为「吧唧钱包」。
- **技能图标**：抽脸改深蓝色，泼屎改墨绿色。
- **动态噪音延迟**：噪音杀伤延迟按 Boss 区段从 3.0s 线性递减到 1.5s（首个 Boss 前 3s，每过一个 Boss 减 0.5s）。
- **门禁修复**：Boss 满员时正确驱逐并入场；Boss 生成不再冻结普通门禁；实现 idleExitSec — NPC 入场超时后强制优先退出，FIFO 循环确保被击败的 Boss 最终离开。
- **塞嘴重做**：自动锁定最远吧唧者，无射程限制，紫色胶囊弹道飞行动画。
- **暂停系统**：HP 左侧 ⏸/▶ 按钮，Esc 切换，tick 早退冻结游戏状态。

## Round 7

- **i18n 国际化**：`src/game/i18n.ts` 扁平字典 + `t(key)` 函数，~100 个 key 三语翻译（中/英/荷）。
- **语言切换器**：开屏标题栏左侧循环按钮 ZH→EN→NL→ZH，非下拉菜单。
- **TTS 语音**：中文用 zh-CN voice，英文和荷兰语共用 en-US voice（荷兰语不另配 TTS）。
- **全量文案翻译**：技能名/描述、开屏、HUD、赞助弹窗、引导提示、道具 toast、称号、NPC 标签、3D 场景文字（墙画/门联/静音符）全部 `t()` 化。
- **墙画/门联英文**：静→Shhh / 忍→Bear It / 食不言→No Smack；天道酬勤→Chew Quiet / 地道的您→Or Else。英文逐字母竖排。
- **荷兰语**：喊话（Hou je fucking bekken dicht!）、技能（Klap/Plakband/Schreeuw/Mondprop/Strontgolf/Beschaafd）、墙画（Sjh/Volhard/Geen Smak）、门联（Kauw Stil/Of Anders）。
- **暂停时间修复**：`pausedAt` 追踪 + `startedAt` 偏移，恢复后游戏时间不跳跃。
- **跳跃翻桌**：空中跳过桌面碰撞；跳跃参数调整为 650ms/1.1 高度（可翻越全部桌子）。
- **吧唧嘴 → Byageee Mouth**：全语言统一。

## Round 8

- **手机开屏修复**：`briefing-card` 从 `overflow: hidden` 改为 `overflow-y: auto`，内容溢出时可滚动，「出警」按钮不再被裁剪不可达。移动端 padding/字号全面压缩（h1 20→18px、lede 12→11px、技能描述 12→11px、间距收紧），减少滚动需求。
- **赞助弹窗溢出修复**：`donation-card` 加 `max-height: 100%` + `overflow-y: auto`，移动端三段文案 + 二维码不再被裁剪。
- **死亡画面安全**：`justify-content: safe center` + `overflow-y: auto`，窄屏横屏下 h1/称号溢出时顶部不被截断。
- **摇杆移动修复**：`TouchControls` 的 `useEffect` 依赖数组缺少 `briefingDone`，导致 briefing 结束后摇杆永不初始化。加入 `briefingDone` 依赖 + effect 内守卫，修复移动端无法移动的致命 bug。
- **技能卡移动端重做**：6 个方形带文字按钮（底部居中横排）→ 6 个圆形纯图标按钮（底部右侧 2×3 网格），54px 直径，冷却/锁定为右下角徽章。隐藏 `kbd` 和技能名文字，减少视觉杂乱。
- **触摸操作按钮重排**：跳跃/切换从右侧底部纵向堆叠 → 移到技能网格正上方横向排列，所有操作按钮集中在右下角，右拇指自然覆盖。

## Space Director

- **空间导演（SpaceDirector）**：首 Boss 击败后奖励式解锁空间事件（扩建新房 A 类 / 原地变形 C 类），后续稀疏随机触发；HUD toast 显示事件名（`spaceEvent_A1`–`C5`）。
- **开门连新房**：所有空间事件统一为「开门 + 连接新房子」——从房间四侧（东/西/南/北）随机选可用方向开门（方向不写死，主厅四侧用尽后从新房间向外扩，全满时降级微调）；扩建（A1/A2/A3/A5 大房多座）与改造（C1 小雅间/C2 幽静隔间/C3 立柱包间/C5 壁橱间/C6 屏风房）都在新房内实现，不再改动主厅；新房间有墙、门洞与朝向正确的门（取代撞门的橱柜）。
- **多房间声学**：威胁按房间衰减；闩门阻隔隔壁噪音；同层跨楼略 muffling，高处无额外减伤。
- **追杀客（chaser）**：惩罚躲清静房；贴脸强制吧唧；NPC 标签 `npc_chaser`；拍击可击退。
- **躲藏与闩门**：短按空格跳跃；家具旁长按躲桌下（移动起身）；门前长按闩门 ~6s。
- **氛围升级**：动态灯光、吧唧雾、角色细节、Bloom/Outline 后处理（移动端质量门控）。
- **i18n**：空间事件、躲藏/闩门提示（`hint_hide` / `hint_latch`）、开屏/HUD 长按空格说明、引导 `guide_4`。

## 剪影与声学

- **NPC 剪影 archetype**：食客随机戴礼帽/圆顶帽/厨师帽/鸭舌帽/丸子头（90% 带帽率），瘦/常/胖三种体型；Boss 固定礼帽+壮实，追杀客无帽瘦高。纯几何，无玩法影响。
- **房间声学混响**：咀嚼声按房间门缩放（邻房/远房更闷更轻、闩门再降一档、追脸追杀客全开）；程序化卷积残响随房间面积变化（小包间更 wet）。

## 成就与分数

- **计分**：存活秒 + 技能命中×10 + Boss×250 + 空间事件×100 + 道具×50 + 击退追杀×75；HUD 实时显示。
- **成就（10 个）**：首杀 Boss、杀 5 Boss、存活 5/10/20 分钟、击退追杀客、首空间事件、拾 10 道具、100 技能命中、满级；解锁瞬间金色 toast，跨局持久化（localStorage）。

## 内容扩充

- **Boss 狂暴脉冲**：半血狂暴 Boss 每 9s 蓄力 1.2s（头顶金色蓄力环）后释放噪音脉冲（解除半径 5m 内静默/密封并催化吧唧，镜头微震）；蓄力期被技能命中即打断（4s 冷却），给玩家明确反制窗口。
- **A5 餐吧角**：东侧新包间，圆桌 4 座 + 吧台桌 2 座 + 吧台障碍。
- **C6 屏风阵**：大厅 3 块错落屏风障碍（挡路不挡声）。

## 楼上扩展（Upstairs）

- **A4 扩建：楼上小包间**：r0 正上方 7×7 二楼（floor 1），圆桌 2 座，北侧楼梯（0.5,−3.2→−0.8）。
- **C4 改造：阁楼平台**：南侧 5×3.4 平台，方桌 2 座，西侧楼梯（−2.5→−0.1）。
- **楼梯机制**：斜坡为 Y 纯函数（`stairYAt`/`agentYAt`），NPC/玩家 XZ 寻路不变，走上/走下 Y 连续无瞬移；楼梯为实心楔形碰撞体（表面贴行、侧面/顶端/脚端进入被挡）。
- **楼层感知**：碰撞按楼层带（楼上桌/墙不挡楼下、楼下桌/墙不挡楼上）；NPC/追杀客可爬楼追人/下楼离开；威胁沿用 floorFactor 跨层衰减；楼梯口不可闩、不渲染门；道具可刷在二楼（拾取楼层感知）。
- **调度**：A4/C4 加入 late 池（weight 2，首奖池不含），`DEFERRED_UPSTAIRS` 已移除；楼上房间不占用地面侧向方向位（availableSides 同层判定）。

## 门与事件反馈

- **门开合动画**：门板铰链摆动——默认敞开（摆向室内），长按闩门后摆回合拢，闩锁到期自动弹开；摆动方向随墙位自动计算（东墙向内摆等），主门与所有侧房门通用。
- **事件音效**：空间事件触发播放重锤 + 敲击音；闩门成功播放木闩声。
- **事件镜头/灯光**：事件瞬间镜头微震 ~400ms，暖色顶灯金色脉冲 ~1.2s。

## 稳定性与性能加固（2026-08）

- **Boss 狂暴脉冲复活**：`tickBossRage` 现在把蓄力中的 boss 写回 `npcs`——蓄力环、打断窗口、脉冲催化（解除封印/催吧唧）与震屏全链路恢复。
- **暂停/切屏时间冻结**：新增 `gameClock.ts` 时间戳平移——tick 检测 >200ms 墙钟间隙，将所有绝对毫秒戳（技能 CD、沉默/封印到期、门闩、追杀客眩晕、事件计时）整体前移，ESC 暂停和切后台不再送免费冷却或跳阶段。
- **击退防穿墙**：`knockbackFrom` 将 >0.3m 位移分段子步进，2.2m 拍飞贴墙滑停，不再瞬移进隔壁房间。
- **每帧重渲染清零**：`props.filter` 条件性重建保持数组引用稳定；threat 订阅量化至 0.05 步长；移动端 Bloom 彻底卸载（原 `intensity={0}` 仍跑渲染链）。
- **阴影收窄**：桌腿/食物/楼梯退出阴影 pass；方向光显式 ±16 shadow-camera 覆盖扩建房间，桌面端 shadow map 升至 2048。
- **共享资源单例**：`materials.ts` / `geometries.ts`——NPC 身体五官帽子、家具食物门框、道具柜子从数百个独立材质/几何实例收敛为约 40 个共享单例（R3F v9 对 prop 传入资源不 dispose，fadeWall 与运行时换色材质保持独享）。
- **首屏 -75%**：`GameCanvas` 懒加载分块；首屏 payload 410KB → 102KB gzip。诊断钩子 `window.__THREE_GAME_DIAGNOSTICS__`（draw calls / FPS / memory）。
- **测试守门**：255 → 284 个测试，覆盖 store 集成狂暴链路、暂停时间冻结、击退穿墙、时钟单元、每日种子确定性。
- **工程**：`.gitattributes` 归一化行尾（根治 CRLF 幻影差异）；oxlint 忽略构建产物；GitHub Actions CI（lint + test + build，push 自动门禁）。

## 产品新特性（2026-08）

- **音量控制**：开屏卡片 🔊 展开音效/喊话语音滑条，按浏览器持久化；噪声缓冲按长度缓存（点击不再重建 Float32Array）。
- **PWA**：可安装、离线可玩——程序化生成的胶带封条图标（192/512，`scripts/make-icons.mjs` 零依赖 PNG 编码），`sw.js` 网络优先导航 + stale-while-revalidate 资源缓存，manifest 适配相对部署。
- **断线续局**：活跃局每 5 秒 + 页面隐藏时快照（2 小时有效期）；刷新后开屏出现「继续上局」，恢复时把全部时间戳按刷新间隙平移，玩法无缝续接；死亡即清除。
- **每日种子挑战**：每天同一种子（日期 FNV 哈希 → LCG 驱动全模拟，与测试同款确定性手法），开屏显示「每日挑战 · 种子 XXX」与今日最佳，死亡结算面板显示种子/得分，同一天内用 R 重开仍是同一局。
